# Mineradio 后续方向

这份笔记记下 2.2.5 之后还值得做的事。原则不变：家族液态毛玻璃是默认语言；新特效只能当可选场景，不能抢文字。

## 已经够用的

- 顶栏 / 侧栏 / 发送栏 / 下拉 / 任务卡 / 目标条 / better-sidebar 面板走同一套玻璃配方
- 流体色相、深浅、色散、粒子、音频响应、壁纸/视频都有旋钮
- 兼容模式会给吃 DSH token 的插件补模糊；实心底、iframe、原生 option 弹层做不到全自动

## 建议优先级

### 1. 场景预设（本轮实现）

设置旋钮已经太多。先给四套一键场景，只改现有旋钮，不改壁纸文件：

| 场景 | 观感 | 主要旋钮 |
| --- | --- | --- |
| 演播室 | 默认香槟金 | 色相 44°、文字香槟、粒子中等 |
| 深海 | 薄荷冷调 | 色相 ~166°、文字薄荷 |
| 午夜 | 玫瑰暖暗 | 色相 ~352°、文字玫瑰 |
| 雾面 | 安静、少动效 | 磨砂升高、粒子压低、辉光/倾斜关掉 |

用户再拧旋钮，场景高亮取消，数值仍可手调。

### 2. 浅色模式过一遍

2.2.x 几乎都在深色下打磨。浅色壁纸 + 浅色玻璃更容易糊、发灰。单独过一遍浅色对比和描边，比再加特效优先。

### 3. 性能档

流体 + 星河 + 色散 + 音频 + 视频叠在一起，弱 GPU 会卡。一个「性能 / 均衡 / 炫」开关，内部只关图层，不删旋钮。

### 4. 设置页分组折叠

外观行已经很长。按「场景 / 材质 / 背景 / 动效」折叠后，上面两档才放得下。

### 5. 可选炫彩流体

可以做，不要当默认。现在流体是单色相。全彩虹会抢字、也容易脏。做成「彩虹带缓慢游走」的第五个场景即可，不要整屏 disco。

### 6. 安装说明

市场更新请走 npm 包 `dsh-theme-mineradio`。`github:` 源会触发 pnpm 构建脚本拦截。主题包本身没有 `prepare` / `postinstall`。

## 明确不做

- 编辑器 / PDF / iframe / 浏览器页做成毛玻璃（内容画布）
- 指望一条通配 CSS 罩住所有第三方插件
- 默认打开音频响应或炫彩流体
