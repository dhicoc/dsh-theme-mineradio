# Mineradio 电台向

2.2.x 把玻璃、场景、性能档、彩虹都做完了。再加旋钮是卫生，不是性格。这份笔记把 Mineradio 当成一台私人视觉电台来想：换的是台，不是主题包。

原则仍旧：家族液态毛玻璃是默认语言；新东西只能当节目，不能抢字。编辑器 / PDF / iframe 仍是内容画布，不上玻璃。

## 电台，不是主题包

### 工作区 = 电台（本轮）

每个 workspace 有自己的呼号频率：侧栏工作区行解析出台名，映射到一组暖调档位（香槟 / 金 / 余烬 / 玫瑰 / 薄荷 / 青碧），localStorage 记忆；切工作区时流体、辉光、色散一起在约 2.2s 内滑到新台，品牌行的小调谐窗显示实时频率（`FM 044`）并轻闪。不加设置旋钮；`prefers-reduced-motion` 下直接落台不滑。存的是偏移量，用户色相旋钮不动，场景预设判定不受影响。

### On Air（本轮）

模型在吐字时，发送栏边缘极慢地呼吸一次，像演播室红灯，而不是音频跳动。停了就灭。没有开关：有停止按钮就是在播。`prefers-reduced-motion` 下不呼吸。

### 空闲是节目表

没会话时流体可以极淡地铺一张「今夜曲目」式的静场——星河排成很淡的频段刻度，一点字都不要抢。有字立刻退。

### 双音，不要彩虹

香槟底 + 一颗可游走的第二音色（薄荷或玫瑰），像立体声左右声道。彩虹是 disco；双音才是电台。彩虹场景已经做成可选，不要再把它当默认方向。

### 调谐手感

色相不要再当一条彩虹滑条。做成刻度盘：阻尼、刻度咔哒、松手吸附到 44 / 166 / 352。功能还是色相，身体记忆完全不同。

## 时间、天气、房间

### 演播室有昼夜

傍晚自动把流体深度拧深一档、文字略暖；清晨略提亮。跟系统浅色 / 深色是两件事：一个是 Appearance，一个是「现在几点」。不要做成节日皮肤。

### 窗，不是壁纸库

壁纸模式可以假装侧栏是窗框：玻璃厚、窗外是你的图，窗框上有一层极淡的冷凝（只在边缘，不在字上）。现在壁纸还是「一张图贴在后面」。

### 房间声学

大聊天区流体松、侧栏流体被玻璃压住——同一套流体，两套「听感」。现在整屏一个场，所以竖纹会从侧栏里喊出来。

## 玻璃当材料，不当贴图

### 三种玻璃

平板（现在）、瓶底（边缘更厚、中间更透）、镜面（几乎不糊、只留高光）。模糊 + 磨砂其实是一个材料的两个错误旋钮。

### 厚度跟随内容

用户气泡薄，助手气泡略厚，思考中再厚一点。还是家族配方，只是厚度在说话。

### 折射按对比度自适应

彩虹 + 高折射会描出竖纹。不要再让人拧出事故。流体对比一高，折射自动锁死。这是物理，不是设置项。彩虹场景已把折射默认拧到 0，自适应是下一步。

### 坏点可以是设计

某一角永远有一颗极淡的气泡瑕疵或一道刮痕，像真玻璃用过。全屏完美反而假。别做成裂纹特效。

## 跟 DSH 咬合

### 会话是碟片

侧栏每一行会话左侧一道极窄的纹片，选中那张在转。这是导航，不是装饰图层。

### token 是音量

上下文越满，磨砂略增、流体略静——保护阅读，不是 VU 表乱跳。

### Agent / 用户分台

子代理气泡走冷台（深海），用户走暖台（演播室）。现在所有玻璃一个腔，对话层次全靠字。

### 截图档

一键：关粒子、关色散、流体停帧、对比拉够。为了发 GitHub / 论坛，不是为了弱 GPU。和「性能档」目的相反：一个为机器，一个为镜头。

## 有点疯、但还像 Mineradio

### 只在你不看的时候演

窗口失焦，星河才走、流体才流；聚焦立刻静。这是电台的后台节目，不是屏保。

### 指针是唱针

不要全屏聚光灯。只有指针底下那一小块玻璃被压出高光，像针落在碟上。

### 一次事故

极低概率，空闲时流体短暂失谐再回到 44°——像电台飘频。不能循环，不能设置里有开关，有开关就俗了。

### 主题会过期

「今夜」场景凌晨失效，回到演播室。有时间性的东西才像广播。

## 如果只做一件

**On Air + 工作区电台。** 不增加旋钮，但 Mineradio 会从「一套很好看的玻璃」变成「这台机器在播某个台」。

其次才是双音（替代继续打磨彩虹）、折射自适应、截图档。

## 明确不做

- 再加一套全屏粒子 / 第二流体 / 默认彩虹
- 玻璃裂开、下雨、雪、节日皮肤
- 给编辑器 / PDF / iframe 上玻璃
- 用模型内容驱动整屏变色（字会输）
- 天气 API、日历节日、桌面小部件
- 自定义场景槽、导出 JSON、记住折叠——那些是卫生，另写，别混进电台向
